---

## 1. Descripción del Ecosistema

El **Minimal Coding Ecosystem** es un subsistema agéntico elástico y modular diseñado para tareas de programación, refactorización y optimización extrema de bases de código. Basado en el paradigma del *Lazy Senior Dev* (repositorio `Nomackleo/ponytail`), este ecosistema reduce drásticamente el volumen de líneas de código escritas (hasta -54%), el consumo de tokens (-20%) y la latencia (-27%), manteniendo al **100% la seguridad, validación de fronteras, manejo de errores y accesibilidad**.

---

## 2. Arquitectura de Guilds y Subagentes

El ecosistema se organiza en el `minimal-coding-guild`:

* `minimal-architect-checker`: Inspecciona la base de código previa, rastrea el flujo real y bloquea dependencias innecesarias reutilizando código preexistente o librerías estándar.
* `minimal-code-refactorer`: Ejecuta refactorizaciones aplicando la Escalera de Deducción (Ladder of Deduction) de 7 niveles.
* `minimal-qa-gatekeeper`: Valida mediante TDD que la simplificación mantenga cero regresiones y 100% de cumplimiento de seguridad (ISO 27001 / SOC 2).

---

## 3. Escalera de Deducción (Ladder of Deduction)

```
1. ¿Es necesario que exista?          → YAGNI (Omitir)
2. ¿Ya existe en esta base de código? → Reutilizar
3. ¿Lo resuelve la librería estándar? → Usar stdlib
4. ¿Es una característica nativa?    → Usar solución nativa (HTML/Browser/OS)
5. ¿Existe en paquetes instalados?   → Reutilizar dependencia
6. ¿Se puede resolver en 1 línea?     → Escribir one-liner
7. Solo en último caso:               → Mínimo código funcional
```
