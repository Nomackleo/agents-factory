# Plantilla de Conocimiento: Sinergia UI/UX (Creatividad Visual vs Accesibilidad Estricta)

**Propósito (WHY):** Servir como *Ground Truth* para regular el uso híbrido de la temperatura y el Top-P dentro del mismo ecosistema, separando la creatividad de diseño del rigor de accesibilidad.

**Audiencia (WHO):** Agentes de Diseño (`Design System Guild`, `UX Guild`) y Agentes Auditores (`Ergonomics & Accessibility Guild`).

## 1. Fase de Ideación y Estética (Creatividad Paramétrica)
Para los Gremios de Diseño de Tokens y Flujos UX:
- **Creatividad Activada:** Se deben explorar paletas atrevidas, micro-interacciones innovadoras y arquitecturas de información fluidas.
- El modelo tiene libertad semántica para idear y proponer experiencias visuales inmersivas. No se limita a esquemas anticuados o aburridos.

## 2. Fase de Auditoría Ergonómica (Rigor Absoluto)
Para el Gremio de Accesibilidad (WCAG, ISO 9241):
- **Censura Cognitiva Activada:** La evaluación de contraste, tamaño tipográfico y accesibilidad para lectores de pantalla se rige con **Temperatura 0**.
- **Regla Inquebrantable:** Si el contraste de un botón creativo propuesto por el `UX Guild` no supera el ratio 4.5:1 (WCAG AA), el Auditor de Accesibilidad lo rechaza sin miramientos lógicos ni interpretativos. La creatividad visual *jamás* anula el rigor ergonómico.

## 3. Sandboxing de Figma / Conexiones Web
Todo intento de un integrador (ej. `figma-stitch-integrator`) de conectarse al API de Figma u otra herramienta de diseño en la web, debe pasar obligatoriamente por la Capa de Control (Triaje ASK/ALLOW/DENY). No se inyectan tokens en proyectos vivos sin autorización explícita del humano.
